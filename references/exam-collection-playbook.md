# 整卷页 / 错题集页 Optimize Playbook

适用对象：题库平台截图流类手写合集页——「整卷页」（全卷作答截图按题序排列）与「错题集页」（错题/重点题专项截图集）。此类页面图片量大（30–300 张）、题面只在截图里、常与详解页/母卷构成三层结构，普通 optimize 流程之外需追加本 playbook 的对账与统计动作。通用方法层，具体领域路径/标签以 vault schema 为准。

## 1. 处理前置

- 无 frontmatter 时按结构性例外补至首行；`created` 取文件 birthtime 日期（正文另有可信标注日期除外）；`updated` 取本次修改日。
- 手写合集页通常无 raw 来源目录 → `sources: []` 并在资料总结写明推导基础；若截图已入 raw 专属目录则 `sources` 指向目录（以 `/` 结尾）。
- 无图片嵌入的纯文字页免 manifest；有嵌入则先建 manifest 再派读图。

## 2. Manifest 双向对账（必做）

| 对账项 | 内容 |
|---|---|
| 嵌入→文件 | 按文档顺序提取全部 `![[...]]`，逐个全库 `find` 验证唯一性，全部须命中 sources |
| 文件→嵌入 | sources 目录中未被嵌入的文件**逐张定性**：先 MD5 比对时间近邻（排除字节级重复），再读图判定 同题另拍 / 解析续页 / 独立题目；结论写页面边界说明，处置权留用户 |
| 跨目录嵌入 | 嵌入唯一命中其他 raw 目录（同图双存）→ sources 登记多目录，不动 raw 文件 |
| 双图拼接 | 题面+解析续页成对的题，在资料总结/对账表注明，coverage 统计按独立题数而非图片数 |

图片数 >10 时派只读 subagent 批次读图（并发受限→串行派发，见 SKILL.md §Subagent 批量分析）；每批给 bounded manifest slice，批次 prompt 注明「数据类截图（题号/答案字母/作答次数/正确率）务必精确转录，不确定标低置信，绝不猜测补齐」。

## 3. 整卷页统计口径

从读图结果拼装（主线程负责跨批 coverage 拼接）：

- **覆盖**：`覆盖题号 / 全卷题数`；缺题截图如实标注「截图缺失、全库无此题」（不臆测作答记录）。
- **作答统计**：有记录题数、答对/答错、正确率；有条件时按 题型（单选/多选）分列——多选通常是失分主战场，跨卷对比有意义。
- **错题清单**：一行一题，格式「题号 | 题型 | 正确答案←我的答案 | 主题」，是全页信息密度最高的表。
- **标注类事实**：平台红字过时标注、附加分层级、低正确率极值（最高/最低），如实转录不解读过度。
- **手写旁注**：逐处记录并定位到相邻题位；旁注常直接点中错因，且会在母卷页与错题集页之间演进（对照可发现补充细节）。
- **详解页链接**：记录链接与其相邻题位的对应关系；「链接题位 ↔ 详解页题号」可回核详解页的题号存疑（跨页证据只注明、不代改对方页面）。

## 4. 错题集页与母卷互证

- **收录构成**：分「真错题收录」与「答对也收录」两类统计；对照母卷错题清单给出覆盖率（如 21/21 全收录）。
- **跨页双读互证**：同一题在母卷页与错题集页各有一张截图、经两条独立读图管线各读一次，题号/答案/作答统计读数应完全一致——不一致即低置信，须回查原图；这是此类页面的天然校验器。
- **疑误收（答对也收录）**：只描述构成、不代删；若低正确率题占多数，可标注「更像主动收集易错题而非误收」的推断（标推论）。

## 5. 追加节模板（放在既有正文之后，正文/嵌入/顺序逐字保留）

```markdown
## 资料总结

图片核对（image manifest）：双向对账表（嵌入数 / 覆盖题数 / 跨目录嵌入 / 未嵌入定性）……

（整卷页）作答统计表：范围 | 有记录题数 | 答对 | 答错 | 正确率
（错题集页）收录构成：真错题清单 + 答对也收录清单

手写旁注逐处说明；详解页链接与题位对应；标注类事实（过时题/附加分）。

## 洞见

（按数据归纳的失分模式、题族聚类、跨卷对比；推论须标注「基于……推导」）

## 方法论提炼 / 最佳实践 / 金句精选

（按用户当次节清单裁剪；金句须出自正文或截图转录）

## 相关 Wiki

（母卷/错题姊妹本/同主题先行详解页；出链前逐一验证目标存在且标题唯一）
```

## 6. index 收录与收尾

- 条目用 vault 惯例链接形式（短链或全路径），插在同类姊妹条目之后（如 (一) 卷之后、错题集（一）之后）；摘要写明 截图数/覆盖题数/统计结论/对账特记事项。
- 按 SKILL.md 写命令 SOP 执行精校 → 三处同步 → **页脚写后复验** → log 一条最终记录（未嵌图处置、缺题、跨目录 sources 等写入 `未决` 字段）。
